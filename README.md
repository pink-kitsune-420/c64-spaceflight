# C64 Spaceflight

Play it: https://pink-kitsune-420.github.io/c64-spaceflight/

An orbital flight sim written in 6502 assembly for the Commodore 64. This
repository holds only the playable page: the real program running on a
small JavaScript C64 written for it. No Commodore ROMs are included; the
lettering is an original stand-in for the C64 character set.

Controls: ← → turn, Space or ↑ fires the engine, Z / X zoom, `,` `.` time
warp, C switches the camera, P shows the physics time in the border. On a
phone, hold the on-screen keycaps.
